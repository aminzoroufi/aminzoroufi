## Circular Battery Decision Twin

[Repository](https://github.com/aminzoroufi/circular-battery-decision-twin) · **Local research prototype**

Connects Unity process simulation, a FastAPI decision backend and a Streamlit dashboard for battery inspection, health/risk evaluation, recovery routing and decision records.

- **Focus:** Data flow between simulation and backend services; traceable engineering decisions.
- **Stack:** Python, FastAPI, Streamlit, Unity/C# and computer-vision components.
- **Status:** Local research prototype. See the repository for dataset assumptions, evaluation and operating limits.

## ReLight-X

[Repository](https://github.com/aminzoroufi/relight-x) · **Simulation prototype**

Models traffic-aware lighting, emergency scenarios, fault fallback and estimated energy use with a Unity visualization and Python simulation workflow.

- **Focus:** Scenario modeling, simulation results and repeatable validation.
- **Stack:** Python, Unity, MQTT, Streamlit and a virtual STM32 node model.
- **Status:** Simulation-first; no certified road deployment or physical hardware validation is claimed.

## AR-GoFa Control Twin

[Repository](https://github.com/aminzoroufi/AR-GoFa-Control-Twin) · **RobotStudio integration**

Links a Unity robot visualization to ABB RobotStudio through EGM/UDP, with a Python bridge for mobile communication.

- **Focus:** Real-time data exchange and connecting a virtual controller to an interactive model.
- **Contribution:** Maintenance and modifications documented in the repository.
- **Status:** Simulation-first setup; see the repository's implementation boundaries.
