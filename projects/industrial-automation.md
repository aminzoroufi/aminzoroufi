## Intelligent Industrial IoT Monitoring Platform

[Repository](https://github.com/aminzoroufi/intelligent-industrial-iot-monitoring-platform) · **Pre-release demonstrator**

An equipment condition-monitoring demonstrator with telemetry ingestion, alarms, device communication and an operator dashboard.

- **Focus:** MQTT telemetry, Modbus interoperability, backend data flow and explainable anomaly detection.
- **Stack:** Python, FastAPI, PostgreSQL, Next.js, MQTT and ESP32/STM32 firmware sources.
- **Contribution:** Amin Zoroufi is listed as project author and maintainer in the repository's AUTHORS.md.
- **Status:** Software and synthetic evidence are marked `SIMULATED`. Embedded builds and physical bench/field verification remain unverified in the documented release status.

## AR-GoFa Control Twin

[Repository](https://github.com/aminzoroufi/AR-GoFa-Control-Twin) · **Industrial communication / simulation**

ABB RobotStudio integration with Cartesian commands, six-axis joint feedback and an interactive Unity interface.

- **Focus:** EGM/UDP communication, integration configuration and simulation-based troubleshooting.
- **Stack:** ABB RobotStudio, Unity/C#, Python, UDP and TCP/IP.
- **Contribution:** Maintained and modified by Amin Zoroufi.
- **Status:** Simulation-first project. Hardware operation requires independent validation of the controller and safety configuration.

## ReLight-X

[Repository](https://github.com/aminzoroufi/relight-x) · **Control-system simulation**

Adaptive lighting logic with emergency response, fault scenarios, telemetry and virtual edge-controller behavior.

- **Focus:** Control logic, fault fallback, monitoring and visualization.
- **Stack:** Python, MQTT, Unity/C#, Streamlit and Wokwi STM32 simulation.
- **Status:** Research and demonstration prototype; physical installation is not claimed.

[Smart Highway Lighting](https://github.com/aminzoroufi/Smart-Highway-Lighting) is a fork of collaborative work with [iamashkan](https://github.com/iamashkan). It explores adaptive lighting, a digital twin and edge-controller simulation.
