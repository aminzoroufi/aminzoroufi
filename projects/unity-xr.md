## AR Museum

[Repository](https://github.com/aminzoroufi/AR_Museum) · **Unity AR prototype**

An augmented-reality museum experience using tracked images and detected planes to position exhibit content and display descriptions.

- **Focus:** AR Foundation integration, tracked-image events, placement logic and camera-facing content.
- **Stack:** Unity 6, C#, AR Foundation, URP.
- **Code to inspect:** [GroundPositioningHandler.cs](https://github.com/aminzoroufi/AR_Museum/blob/main/Assets/Scripts/GroundPositioningHandler.cs) and [PlaneClassifier.cs](https://github.com/aminzoroufi/AR_Museum/blob/main/Assets/Scripts/PlaneClassifier.cs).
- **Status:** Unity source project; device-demo evidence is not included in this collection.

## AR-GoFa Control Twin

[Repository](https://github.com/aminzoroufi/AR-GoFa-Control-Twin) · **Mobile / desktop digital-twin project**

A Unity interface that visualizes the ABB GoFa robot and exchanges Cartesian commands and joint feedback with RobotStudio.

- **Focus:** C# integration, live joint visualization, networking and mobile/desktop configuration.
- **Stack:** Unity, C#, ABB RobotStudio, EGM/UDP, Python.
- **Contribution:** Maintained and modified by Amin Zoroufi, as documented in the repository.
- **Status:** Simulation and mobile-control workflow. AR plane detection, anchoring and spatial registration are not implemented in this repository.

## ReLight-X

[Repository](https://github.com/aminzoroufi/relight-x) · **Simulation prototype**

A Unity night-highway digital twin with traffic scenarios, selectable vehicles, interactive luminaires and emergency-response visualization.

- **Focus:** Scene interaction, runtime visualization and connecting simulation state to the operator interface.
- **Stack:** Unity 6, C#, Python, MQTT, Streamlit.
- **Evidence:** Screenshots and implementation documentation in the repository.
- **Status:** Software simulation; road deployment and physical hardware are not claimed.
