## Industrial monitoring dashboard

[Web source](https://github.com/aminzoroufi/intelligent-industrial-iot-monitoring-platform/tree/main/web) · [Project documentation](https://github.com/aminzoroufi/intelligent-industrial-iot-monitoring-platform)

The operator dashboard of the Industrial IoT Monitoring Platform.

- **Focus:** A Next.js interface connected to FastAPI and telemetry services.
- **Context:** Part of an engineering demonstrator with simulated device data.
- **Status:** Pre-release; see the repository for the documented verification status.

## Industrial Scan Twin browser interface

[Web source](https://github.com/aminzoroufi/industrial-scan-twin/tree/main/web) · [Project documentation](https://github.com/aminzoroufi/industrial-scan-twin)

A browser interface for inspecting uploaded scan data, assets and annotations.

- **Stack:** HTML, CSS, JavaScript, Canvas and a local Node.js backend.
- **Status:** Early local MVP.
